Auth & Authorization (RBAC)

Secure user and admin authentication. Route-level Role-Based Access Controls restrict sensitive administrative functions.

🛡️

Session Hijacking Mitigations

Protections against session fixation and hijacking by binding sessions to User-Agent/IP hashes and using secure SameSite cookies.

🔐

AES-256-GCM Encryption

Sensitive data is encrypted at rest using industry-standard AES-256-GCM. Passwords are secured using salted Bcrypt hashing.

📲

Multi-Factor Auth (MFA/TOTP)

Optional two-factor authentication (TOTP) utilizing Google Authenticator or standard authenticator apps with dynamic QR codes.

🚫

Rate Limiting & CAPTCHA

Mitigation against brute force and automated attacks using custom mathematical CAPTCHAs and express rate limiting.

📝

STRIDE & DREAD Audits

Extensive threat modeling and risk assessments mapped to system design, ensuring mitigations for every structural risk.
